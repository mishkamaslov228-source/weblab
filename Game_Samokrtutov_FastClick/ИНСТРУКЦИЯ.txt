ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ ИГРОВОГО ПРИЛОЖЕНИЯ
"Координация по времени"


ЗАПУСК ПРИЛОЖЕНИЯ


1. Откройте файл index.html в любом современном браузере
   (Chrome, Firefox, Safari, Edge)

2. Введите ваше имя в поле ввода

3. Нажмите кнопку "Начать игру"


СТРУКТУРА ИГРЫ


Игра состоит из 3 уровней:

УРОВЕНЬ 1: Реакция
- На экране появятся отвлекающие элементы и кнопка "НАЖМИ СЕЙЧАС!"
- Кнопка появится через 2-6 секунд (зависит от сложности)
- Кнопка плавает по экрану вместе с отвлекающими элементами
- Можно нажимать любой кнопкой мыши, пробелом или Enter
- Чем быстрее ваша реакция, тем больше баллов вы получите
- Внимание! На экране будут отвлекающие элементы
- Двойной клик по отвлекающим элементам удаляет их
- Наведение на элементы меняет их размер

УРОВЕНЬ 2: Определение интервала
- На экране будут мигать лампочки с определенным интервалом времени
- Лампочки могут мигать быстро, так что будьте внимательны!
- Определите время между включениями лампочек (в секундах)
- Наблюдайте внимательно за ритмом вспышек
- Введите время в поле ввода и нажмите "Ответить" или клавишу Enter
- Чем точнее ваш ответ, тем больше баллов!
- Наведение на лампочки увеличивает их размер

УРОВЕНЬ 3: Координация и точность
- На экране движутся различные объекты, среди них есть целевые объекты
- Целевая зона находится справа вверху
- Доставьте все целевые объекты в целевую зону
- Кликните на целевой объект, чтобы выбрать его
- После выбора объектом можно управлять клавишами WASD:
  W - вверх
  S - вниз
  A - влево
  D - вправо
- Также можно перетаскивать выбранный объект мышью
- Можно перетаскивать любые объекты мышью
- Двойной клик по объекту ускоряет его движение
- На каждом подуровне меняется цель (цвет или эмодзи)
- На последнем подуровне нужно перенести 3 объекта с определенным эмодзи





СИСТЕМА БАЛЛОВ


- Баллы начисляются за точность выполнения заданий
- Чем точнее выполнение, тем больше баллов
- Штрафные баллы вычитаются за ошибки и опоздания
- Сложность влияет на множитель баллов
- На первом уровне баллы зависят от скорости реакции
- На втором уровне баллы зависят от точности определения интервала
- На третьем уровне баллы зависят от скорости и количества пойманных объектов


НАСТРОЙКИ


В главном меню доступны настройки:

1. Цветовая тема:
   - По умолчанию
   - Темная
   - Синяя
   - Зеленая
   - Фиолетовая

2. Сложность:
   - Легкая (больше времени, меньше скорость, мягкие требования)
   - Средняя (стандартные параметры)
   - Сложная (меньше времени, больше скорость, строгие требования)

3. Режим отладки:
   - Позволяет переходить к любому уровню напрямую
   - Полезно для проверки уровней без прохождения с начала
   - Появляется в правом верхнем углу игрового экрана


РЕЙТИНГ


- Все результаты сохраняются автоматически после завершения игры
- Рейтинг можно просмотреть на странице "Рейтинг"
- Доступна сортировка по баллам и по дате
- Можно очистить рейтинг (кнопка "Очистить рейтинг")
- Сохраняются только топ 100 результатов

УПРАВЛЕНИЕ


- Кнопка "Пауза" - приостанавливает игру
- Кнопка "Выход" - выход из игры (прогресс не сохраняется)
- После завершения уровня можно перейти к следующему
- После завершения всех уровней можно начать игру заново
- При паузе во время игры текущий подуровень начнется заново
- Есть общий таймер игры, который ограничивает время прохождения


ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ


- Современный браузер с поддержкой JavaScript
- Локальное хранилище (localStorage) должно быть включено
- Рекомендуется использовать последние версии браузеров
- Игра адаптирована для разных устройств (десктопы, планшеты, мобильные)


СОХРАНЕНИЕ ДАННЫХ


Все данные сохраняются в localStorage браузера:
- Имя текущего игрока
- Настройки игры (тема, сложность, режим отладки)
- Рейтинг игроков (топ 100)

Данные сохраняются автоматически и остаются после закрытия браузера.


ОСОБЕННОСТИ ИГРЫ


- Каждый уровень состоит из 4 подуровней
- С каждым подуровнем сложность увеличивается
- Случайная генерация элементов для разнообразия
- Анимация элементов для улучшения восприятия
- Адаптивный дизайн для разных устройств
- Поддержка русской и английской раскладки клавиатуры на уровне 3


ПОДДЕРЖКА
При возникновении проблем:
1. Убедитесь, что JavaScript включен в браузере
2. Проверьте, что localStorage доступен
3. Обновите страницу (F5)
4. Очистите кэш браузера при необходимости
5. Используйте последние версии браузера
