Правила игры

  • Игра состоит из 3 уровней различной сложности
  • На каждом уровне вам нужно выполнить 3-5 заданий
  • Баллы начисляются за точность и скорость
  • За ошибки и опоздания начисляются штрафные баллы
  • Игра ограничена по времени
  • Переход на следующий уровень возможен только после успешного прохождения предыдущего
