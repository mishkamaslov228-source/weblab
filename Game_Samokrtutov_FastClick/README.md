# Игровое приложение "Координация по времени"

## Описание

Веб-приложение для развития чувства времени и координации движений. Игра состоит из трех уровней различной сложности, каждый из которых проверяет разные навыки временной координации. Приложение полностью работает на чистом HTML/CSS/JavaScript без использования фреймворков.

## Функциональность

### Основные возможности

1. **Миниавторизация** - ввод имени игрока (только имя)
2. **Рейтинг игроков** - сохранение и отображение результатов (топ 100)
3. **3 уровня игры** - различные типы заданий, каждый уровень имеет 4 подуровня
4. **Система баллов** - начисление и штрафы, зависимость от сложности
5. **Таймер** - ограничение времени игры (зависит от сложности)
6. **Настройки** - выбор темы и сложности
7. **Режим отладки** - прямой переход к уровням для тестирования
8. **Адаптивный дизайн** - поддержка разных устройств (десктопы, планшеты, мобильные)

### Уровни игры

#### Уровень 1: Реакция
- **Задача**: как можно быстрее нажать на кнопку "НАЖМИ СЕЙЧАС!"
- Кнопка появляется через 2-6 секунд (зависит от сложности)
- Кнопка плавает по экрану вместе с отвлекающими элементами
- Можно нажимать любой кнопкой мыши, пробелом или Enter
- Отвлекающие элементы с анимацией (количество и скорость зависят от подуровня)
- Обработка двойного клика и наведения на отвлекающие элементы
- На последнем подуровне отвлекающие элементы имеют такой же размер как кнопка
- 4 подуровня с увеличением сложности

#### Уровень 2: Определение интервала
- **Задача**: определить время между включениями лампочек (в секундах)
- Количество лампочек увеличивается с каждым подуровнем
- Визуальная обратная связь при мигании
- Обработка клавиши Enter для отправки ответа
- Наведение на лампочки увеличивает их размер
- Чем выше подуровень, тем больше лампочек
- 4 подуровня с разными интервалами и количеством лампочек

#### Уровень 3: Координация и точность
- **Задача**: доставить все целевые объекты в целевую зону (справа вверху)
- Кликните на целевой объект для выбора
- После выбора объектом можно управлять клавишами WASD (независимо от раскладки)
- Также можно перетаскивать выбранный объект мышью
- Перетаскивание любых объектов мышью
- Двойной клик для ускорения объектов
- Анимация движения объектов
- На каждом подуровне меняется цель (цвет или эмодзи)
- На последнем подуровне нужно перенести 3 объекта с определенным эмодзи
- Внутренний таймер для каждого подуровня (25-20-15-10 секунд)
- Если не успели - подуровень начинается заново
- 4 подуровня с увеличением сложности и количества объектов

### События

Игра использует различные типы событий:

- **Перетаскивание** (drag & drop) - уровень 3
- **Двойной клик** (dblclick) - уровни 1 и 3
- **Наведение** (mouseenter/mouseleave) - все уровни
- **Клавиатура** (keydown/keypress) - все уровни:
  - Level 1: Space, Enter
  - Level 2: Enter
  - Level 3: WASD (поддержка русской и английской раскладки)
- **Клик мыши** (click/mousedown) - все уровни
- **Движение мыши** (mousemove) - уровень 3

### Система баллов

- Баллы начисляются за точность выполнения заданий
- Штрафные баллы за ошибки и опоздания
- Множитель сложности влияет на начисление баллов:
  - Легкая: 0.8x
  - Средняя: 1.0x
  - Сложная: 1.3x
- Бонусы за скорость выполнения
- На первом уровне баллы зависят от скорости реакции (требования зависят от сложности)
- На втором уровне баллы зависят от точности определения интервала
- На третьем уровне баллы зависят от скорости и оставшегося времени

### Настройки

- **Цветовые темы**: По умолчанию, Темная, Синяя, Зеленая, Фиолетовая
- **Сложность**: 
  - Легкая (больше времени, меньше скорость, мягкие требования)
  - Средняя (стандартные параметры)
  - Сложная (меньше времени, больше скорость, строгие требования)
- **Режим отладки**: Прямой переход к любому уровню (отображается в правом верхнем углу игрового экрана)

### Дополнительные функции

- **Пауза** - можно поставить игру на паузу в любой момент
- **Правила уровней** - перед каждым уровнем показываются правила
- **Модальные окна** - для правил, завершения уровня, завершения игры, паузы
- **Адаптивный дизайн** - игра работает на разных устройствах и размерах экранов
- **Сохранение прогресса** - результаты сохраняются автоматически после завершения игры

## Запуск

1. Откройте `index.html` в современном браузере
2. Введите имя игрока
3. (Опционально) Настройте тему и сложность в настройках
4. Нажмите "Начать игру"

## Технические требования

- Современный браузер с поддержкой ES6+
- Локальное хранилище (localStorage) должно быть включено
- JavaScript включен
- Поддержка CSS3 анимаций
- Рекомендуется использовать последние версии браузеров

## Сохранение данных

Все данные сохраняются в localStorage браузера:
- Имя текущего игрока
- Настройки игры (тема, сложность, режим отладки)
- Рейтинг игроков (топ 100)

Данные сохраняются автоматически и остаются после закрытия браузера.

## Особенности реализации

- **Чистый HTML/CSS/JavaScript** - без фреймворков и библиотек
- **Динамическое создание элементов** - все игровые элементы создаются динамически
- **CSS анимации** - использование @keyframes для плавной анимации
- **Адаптивный дизайн** - медиа-запросы для разных устройств
- **Модульная архитектура кода** - разделение на отдельные модули
- **Случайная генерация** - элементы и параметры генерируются случайно
- **Обработка событий** - различные типы событий для интерактивности
- **Поддержка клавиатуры** - независимо от раскладки (используется e.code)

## Структура кода

Код организован в отдельные модули:
- `game-engine.js` - управление игровым процессом, таймер, баллы

- `game.js` - координация работы уровней и модальных окон
